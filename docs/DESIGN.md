# 设计规范

样式只有一套刻度，token 定义在 `scripts/collect.html` 的 `:root`。**本规范仅适用于 OpenGems 本身。**

## 尺度

| 项 | 取值 |
| --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（8pt 网格，微调只用 4） |
| 字号 | 11 / 12 / 13 / 14 / 15 / 20 / 24 / 56 |
| 行高 | 16 / 20 / 22 / 28 / 32 / 64（正文 14 / 22） |
| 字重 | 400 正文 / 500 强调 / 600 标题 / 700 展示 |
| 圆角 | 6 / 8 / 12 / 16 / 999 |
| 容器 | 1120px，左右留白 32（移动端 20） |

## 控件

| 控件 | 规格 |
| --- | --- |
| 搜索框 / 图标按钮 / 收藏按钮 | 高度 **32px**，圆角 **8px**，图标 16px |
| 详情页主按钮 | 高度 **36px**，宽度固定（收藏 128px） |
| 按钮圆角 | `border-radius: 8px` + `corner-shape: superellipse(1.5)`（超椭圆） |
| 图标 | `viewBox="0 0 16 16"`、`stroke-width="1"`、渲染 16px；描边需要不随尺寸缩放时加 `vector-effect: non-scaling-stroke` |

## 颜色

深色与浅色两套必须同时改（`:root` 与 `:root[data-theme="light"]`）：

| token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#151517` | `#e2e6ec` | 页面底色 |
| `--panel` | `#232324` | `#ffffff` | 卡片、面板 |
| `--panel-2` | `#2c2c2e` | `#edf0f5` | chip、次级块 |
| `--line` | `rgba(255,255,255,.06)` | `rgba(15,23,42,.10)` | 描边 |
| `--line-soft` | `rgba(255,255,255,.04)` | `rgba(15,23,42,.06)` | 分隔线 |
| `--text` | `#f9fafb` | `#0f1115` | 主文字 |
| `--muted` | `#adb2b8` | `#61666b` | 次要文字 |
| `--accent` | `#4d93f8` | `#2563eb` | 强调、选中态 |
| `--ok` | `#22c55e` | `#22c55e` | 收藏、成功 |
| `--warn` | `#f59e0b` | `#f59e0b` | 星标 |
| `--danger` | `#ff453a` | `#ff3b30` | 取消、危险操作 |

浅色模式下卡片额外使用 `--shadow` 一层柔和投影，否则白卡在浅底上边界太弱。

## 交互约定

- hover 只改变背景与文字色，**不出现强调色描边**
- 强调色（`--accent`）只用于选中态、链接和进行中的动作
- 危险动作（取消收藏）需二次确认，确认态按钮为实心 `--danger`
- 忙碌状态按钮保持原宽度，避免文字变化导致布局跳动
